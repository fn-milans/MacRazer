Serpentine, as a window

Serpentine's job is to write every setting into the mouse, so the usual session is short: open, set up the mouse, quit. The window is built for that. A few features only work while the app runs, so it can also stay in the background with a small menu bar item.

Where a setting lives

Every row says whether it's in the mouse

The distinction is the product, so the UI shows it on every control, not in a help page.

Saved in the mouseWritten to onboard memory. Works with Serpentine closed, on any link, on any computer. DPI and stages, polling, lighting, sleep timer, scroll settings, profiles, onboard remaps.

What's in the window

  • Sidebar lists connected mice, then the selected mouse's sections. Sections it lacks don't appear.
  • Toolbar shows the link, the onboard profile (colour and name as the mouse has them) and whether the last write reached the mouse.
  • Each pane is one of the per-feature views from the refactor, so the menu bar version and the window share code during the move.
  • The amber banner appears only when a driver-mode setting is in use and background mode is off.
  • About 960×640, minimum 780×540, single window.

How background mode behaves

  • Off by default. Turning on a driver-mode feature offers to turn it on and lists what needs it.
  • On: closing the window keeps the app alive with no Dock icon; this item opens it again.
  • Launch at login exists only in background mode and starts hidden.
  • Upgraders from the menu bar version get it turned on once.

Icons

App icon concepts

Original drawings, no licence obligations, no Razer triskelion. Shown at 200, 64, 32 and 16 points.

A · Coil · recommended

A serpent forming an S. Holds up at 16 px, and its outline is the menu bar glyph, so the two read as one family.

B · Serpent mouse

The button split is the serpent. Says "mouse app" first; the S is lost below 32 px.

C · Ouroboros

A serpent ring around a scroll wheel. The most decorative; busy at small sizes.

Menu bar glyph

A template image: drawn black, macOS tints it for light and dark menu bars. The charging variant keeps the yellow bolt the app uses today.
